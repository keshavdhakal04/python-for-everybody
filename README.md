# Python for Everybody – Practice Repository

This repository contains my practice programs and exercises from the **Python for Everybody** specialization offered by the **University of Michigan** on **Coursera**.

## About the Course

The Python for Everybody specialization focuses on building a strong foundation in Python programming, data structures, web data access, and working with databases.

## Course Structure

### 1. Getting Started with Python

Topics covered:

* Variables and expressions
* Conditional statements
* Functions
* Loops and iteration
* Strings
* File handling

### 2. Python Data Structures

Topics covered:

* Lists
* Dictionaries
* Tuples
* String manipulation
* Data processing

### 3. Using Python to Access Web Data

Topics covered:

* Regular expressions
* Networking with Python
* Web scraping
* XML parsing
* JSON parsing
* Working with APIs

### 4. Using Databases with Python

Topics covered:

* SQLite databases
* SQL queries
* Database design
* Python database integration

### 5. Retrieving, Processing, and Visualizing Data

Topics covered:

* Data analysis
* Data visualization
* Processing datasets
